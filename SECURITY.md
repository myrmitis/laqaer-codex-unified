# Security Policy

Codex Unified is pre-release software that handles local model routing,
credentials by reference, and browser-backed provider sessions.

## Reporting a vulnerability

Do not include credentials, cookies, bearer tokens, raw browser storage, private
prompts, or local capability URLs in a public issue.

For now, report only reproducible security findings that can be described
without those secrets. Private vulnerability reporting should be enabled before
the first public release.

## Supported versions

Only the latest commit on `main` is considered supported during pre-release
development.
